# 用既有 Notion 協作

入口：[課程 Notion](https://app.notion.com/p/3ee3ba51f1c380e4b1e7e5b1ebabe2e0?source=copy_link)。本次無法讀取這個頁面的現有內容，因此以下是建議安排與可貼上的素材，並未在線上新增頁面或資料庫；若原頁面已有相同用途，直接沿用。

## 只保留三個協作區塊

1. **本週進度**：每週一頁，三人各寫自己的成果、來源、限制和提問；同頁下方記教授／助教回饋。使用 [週報模板](weekly_update_template.md)。
2. **任務表**：以 T01–T15 追蹤主責、截止、狀態與成果位置。日常狀態只在這裡更新。
3. **成果與來源**：集中放簡報／正式文件連結，來源與 AI 紀錄直接附在各人的任務或週報下方。先不用再建立多套資料庫或自動化。

每人每週實際研究與產出 2–4 小時，包含與 AI 協作、自己檢查、Notion 及簡報。週一 30 分鐘師生會議另列。AI 用來提高產出，不代表每一項任務都能以固定倍數加速。

## 任務表怎麼開始

本地 [notion_tasks.csv](notion_tasks.csv) 提供 15 項任務的初始內容。可以匯入可編輯的 Notion 頁面，也可以依欄位貼進現有表格；這是一次性搬入，不是雙向同步。已有任務時按 **ID** 更新，避免重新整批匯入產生重複任務。

| 欄位 | 用法 |
|---|---|
| 任務、ID | 任務名稱以 T01–T15 為固定索引 |
| 主責 | 使用「倢安／彥谷／麗賢／三人各自」文字；只有已知 Notion 帳號時才改為人員欄位 |
| 優先度 | 核心／暫緩；T11 未列入本輪工時預算 |
| 交付截止 | 內部交稿，原則為週日 20:00；以臺灣時間為準。匯入後確認時間沒有遺失 |
| 週報日期 | 成果要出現在哪一個週一的簡報 |
| 預估實際投入h每人 | AI 協作下的任務粗估；不是原先人工工時的保證折算 |
| 狀態 | 待認領／進行中／卡住／已交付／暫緩 |
| 本人自檢 | 尚未記錄／已記錄；在任務內寫實際做了哪些檢查，不指派另一位組員簽核 |
| 完成條件、依賴或資料缺口 | 沿用工作計畫；未取得的資料不當作零或已驗證 |
| 成果位置、本週進度或卡點 | 貼可開啟的文件／檔案連結與一句進度 |

「三人各自」的 T01、T14、T15，在同一任務下分三人的小段落或勾選欄，記錄各人交付；一個人完成不代表三個人都完成。CSV 保留本地追蹤表已有狀態及備註，不推定線上任務狀態。

一開始能看「本週到期」和「主責」即可，不要求先設計複雜看板。來源與 AI 紀錄放在任務正文，避免只為了填表花掉研究時間。

## 每週怎麼使用

| 時點 | 誰更新什麼 |
|---|---|
| 平日做事時 | 各人直接附自己的成果連結、來源、限制。AI 找到的來源由引用者親自開啟；程式由作者查看實際執行結果 |
| 週日 20:00 前（內部建議） | 各人完成自己的週報段落及 1–2 頁簡報，記本人自檢。只給最多一個最需要師生決定的問題 |
| 週一 13:30 前（內部建議） | 彥谷合併檔案與格式；內容有錯請作者修改，不設他人查核關卡 |
| 週一 14:00 前 | 彥谷按課程指定方式繳交，貼最終檔案及繳交紀錄；Notion 有檔案不等於已完成課程繳交 |
| 週一 14:30–15:00 | 討論本週結論與待決定問題，不另排固定組內例會 |
| 會後 5–10 分鐘 | 各人記自己項目的回饋、下一步與期限，更新相關任務 |

週一議程可用「3 分鐘現況、12 分鐘三人成果、12 分鐘待決定問題、3 分鐘記下一步」。教授／助教未明確回覆的問題仍標待確認，不能把開過會當作結果已被認可。

12/14 14:00–15:30 期末發表取代一般例會；每週簡報與期末書面的繳交方式依課程公告。12/21 書面截止時刻未確認，不套用每週 14:00 的期限。

## 本人自檢只記有做過的事

每次交付用幾句話回答：來源在哪、單位與服務範圍是什麼、實際重算還是讀快取、檢查了哪個輸出、哪些仍是假設。這些時間計入任務，不新增一輪他人審查。

- 路線作者：自己確認門市／需求沒少算、全品牌車趟與里程都有列、服務或容量違規有揭露。
- 資料與排放作者：自己確認來源與係數、單位、情境版本與換算，沒有把已含怠速的油耗再加一次。
- 文獻與成本作者：自己查看原文、頁碼、費用範圍與未知項目，沒有把線索寫成事實。

完成狀態是「已交付」，不是「已被另一位組員驗證」。無法重現或只完成部分測試，照實寫在限制欄，不延伸成已證實的結論。

## 檔案只存一份用途

Notion 存進度、回饋與成果連結；Git 存分析程式、正式說明和確定保留的產物。

Notion 內的成果位置盡量使用其他組員能開啟的共享連結；本地相對路徑可作專案索引，但不直接當成網頁超連結。不直接貼個人電腦的 `C:\Users\...` 路徑要求組員開啟。

每週簡報建議檔名 `YYYY-MM-DD_progress.pdf`，定稿可放 `docs/presentations/`；各人的來源、AI 紀錄、圖表直接隨任務累積為報告段落，避免期末另抄一份。
